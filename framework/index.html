  • 第三方账户有可用余额和模型权限。
  • API Key 只写入本机配置，不进入 Git 和日志。
  • 先用最便宜的可用模型测试，再切换强模型。
  • 真实模式仍不能跳过 Supervisor 和两次人类审核。
